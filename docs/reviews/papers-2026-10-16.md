## Resource availability

- **JevSpawn:** the paper links [Hoyant-Su/JevSpawn](https://github.com/Hoyant-Su/JevSpawn). Its public tree and README expose a core implementation, configuration and demo. This review did not run them.
- **MetaEncoder:** the paper links [facebook/meta-encoder-eval](https://github.com/facebook/meta-encoder-eval) and a [model page](https://huggingface.co/facebook/meta-encoder). The README's evaluation-code link is intentionally narrower than a claim that all training material has been reproduced or released.
- **Reading Right, Acting Wrong:** no dedicated code repository for this study was verified. Links to referenced models and evaluation toolkits are not presented as this paper's implementation.
- **DecisionRobust:** the primary [benchmark website](https://yifan-lan.github.io/DecisionRobust/) links [code](https://github.com/Yifan-Lan/DecisionRobust) and [data](https://huggingface.co/datasets/yflantmy/DecisionRobust). Its protocol distinguishes attack types, valid-pair denominators and coverage; a single unqualified attack-success number would lose that context.

The additions fill gaps in action-space composition, multimodal encoder design, behavioral diagnosis and robustness. They are newly found for this collection, not papers first published on the review date. No performance ranking or claim about Jev's unpublished architecture follows from their inclusion.

## Follow-up selection — open baselines and inference budgets

A second pass adds three studies already present in the source ledgers but absent from the curated list: **28 direct papers, 36 bibliography entries and 67 curated resources** after this addition. No raw ledger or checked-source count changes are made by this selection.

We checked primary arXiv metadata and abstracts, targeted method and limitation sections, and linked repository READMEs and file listings. This is a scoped editorial review, not full-paper reading, code execution or reproduction. All three remain preprints with author-reported findings.

| Paper and authors | First submission → reviewed version | Interpretation limit |

| [JevCascade](https://arxiv.org/abs/2610.07716v2) — Ran Li, Lei Chen | 2026-10-06 → v2, 2026-10-10 | Menu-intervention stability concerns rankings, not calibrated probabilities; deployment depends on candidate recall. |

The [Inner Jev repository](https://github.com/j-geuter/jeff-serve) supplies serving code, with [OpenDecisions](https://huggingface.co/datasets/jgeuter/OpenDecisions) separately published. The [SanSi repository](https://github.com/minnesotanlp/Sansi) contains data builders, training and main-evaluation code, but explicitly omits external-system baselines, the verifier study, training ablations and some analyses. [JevCascade](https://github.com/rlisml/jev-cascade) exposes data and experiment scripts. Public files do not establish that all reported experiments are independently reproducible.

The JevCascade title follows arXiv **v2**; the Hugging Face metadata inspected still used an earlier title. Exact titles, complete authors and fixed version URLs are in [references.bib](../../references.bib).
